Quest Recorder patch notes - LethToxic

1.0g
- Heroic shuttles: short hops are taken too. A shuttle counts as needed when you're further than half the hop
  you made (between 15 and 100 m) - Saving Face (a 50 m hop) used to get walked.

1.0f
- Mission pickups are back to the 1.0b check: dailies and heroics only if they're not in your log and not done,
  weeklies only if they're not in your log. Rebuild profiles made with 1.0c-1.0e ("Make profile from a recording").

1.0e ("Make profile from a recording").

1.0e
- Fixed: 1.0c and 1.0d left the fights out of new profiles. Please rebuild any profile you made with them
  ("Make profile from a recording").
- Mission items used several times for one task (like the Radiation Sensor for the spies) are used once per count.
- A guessed object has to be near where the quest moved on (no more walking off to a same-named thing elsewhere).
- The game's hidden helper quests don't add walk steps any more.

1.0d
- Fixed the bot standing still at the wrong object: when the recorder couldn't see what you did for a quest
  (like identifying spies in the Black Hole), it sometimes picked an object you only used later. Now it only
  ever picks something you'd already used at that point.

1.0c
- Fixed BuddyCron crashing when loading some recorded profiles (a recording that ended on an elevator, or
  a quest you got without a giver, left an empty step in the profile).
- Weeklies, dailies and heroics get picked up again whenever the game offers them (weeklies up to 3 times
  a week), and the profile doesn't loop forever on a weekly.
- Shorter wait after a Heroic Transport (5 seconds instead of 10).

1.0b
- Runs smoother: profiles no longer have a walk point every few metres - BuddyCron's navigator does the walking.
  They only keep what matters: clicks, talks, fights, doors, lifts, shuttles, rewards.
- Heroic shuttle steps no longer pause for 10 seconds when there's no shuttle to use.

1.0a
- Checks for updates as soon as BuddyCron starts, even if Quest Recorder isn't ticked.
- The update pop-up now shows on top of the game instead of hiding behind it.

1.0
First proper release. Play it once, get the profile.
- Records everything you do by hand and turns it into a profile that does it the same way.
- Heroic Transport shuttles, mission items, elevators, puzzles, boss terminals, NPC clicks,
  looting bodies, rewards (weekly included).
- Live task tracker with "!!" when something was missed, plus an in-game heads-up.
- Control panel: fix or build a profile without touching the XML. It only offers what BuddyCron doesn't
  already do by itself (taxis, elevators, quick travel, vendoring and looting are automatic).
- Make a profile from any old recording.
- Update pop-up, so you never have to download it again by hand.
- "Recorded by <your name>" credit if you want it.
- Ctrl+Shift+Z undo, Ctrl+Shift+M marker.

Coming from the beta (3.x)? Install 1.0 once by hand or with Install Quest Recorder.bat -
the beta's updater won't see it. Updates are automatic from here on.
