# Quest Recorder - a BuddyCron plugin by LethToxic

Play a quest area by hand once; Quest Recorder turns it into a ready-to-load BuddyCron questing profile that plays it the way you did.

## Install
1. Download the newest `QuestRecorder-x.y.z.zip` from this page.
2. Unzip it into your `BuddyCron\Plugins` folder (you get `BuddyCron\Plugins\QuestRecorder`).
3. Restart BuddyCron and tick **Quest Recorder** in the plugin list.

After that, the plugin tells you when there is an update: click **Updates** in its window.

Full instructions are in the README.txt inside the zip.
