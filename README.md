# Quest Recorder

A BuddyCron plugin by LethToxic. Play something once and it makes the profile for you.

Turn it on, do the quests yourself, and you end up with a profile that does them the same way - same clicks,
same order, same fights. Then fix anything you want in the control panel, no XML.

## Install

Grab **Install Quest Recorder.bat**, drop it in your BuddyCron folder and double-click it. It downloads the
latest version for you. Start BuddyCron and tick Quest Recorder.

Or do it by hand: download the latest `QuestRecorder-x.y.z.zip`, unzip it into `BuddyCron\Plugins` and
restart BuddyCron.

After that you get a pop-up whenever there's an update.

More info is in the README.txt inside the zip.
